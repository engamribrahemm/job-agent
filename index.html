ابني AI Agent يدورلك على شغل ويقيمك من 100

بـ Cursor وCallMeBot بس، والاتنين بخطة مجانية. مش محتاج تكتب كود: Cursor هو اللي بيكتبه من الـ Prompts اللي تحت.

الـ Agent بيعمل إيه

1
ياخد بياناتكالـ CV، البورتفوليو، والمسميات الوظيفية اللي بتدور عليها.
2
يدور على الوظايفيبحث في الوظايف المنشورة اللي تناسب خبرتك، ويشيل اللي شافه قبل كده.
3
يقيمك من 100يقارن كل إعلان بالـ CV ويطلعلك المهارات اللي ناقصاك.
4
يبعتلك على واتسابرسالة فيها لينك الوظيفة وتقييمك، وانت تقدم بنفسك في دقيقة.

الأدوات

C
Cursorالـ Agent نفسه: يكتب الكود، يدور، ويقيم. الخطة المجانية فيها عدد محدود من طلبات الـ Agent، فشغله مرة في اليوم.
W
CallMeBotيبعت رسالة واتساب لرقمك انت. مجاني للاستخدام الشخصي.
Py
Pythonبيشغل سكريبت الواتساب الصغير اللي Cursor بيكتبه.

الخطوات

1

شغل CallMeBot

سيف رقم البوت في الـ Contacts، وابعتله على واتساب الجملة دي. هيرد عليك بالـ API key. الرقم موجود في صفحتهم.

الرسالة
I allow callmebot to send me messages

لو المفتاح ماوصلش خلال دقيقتين، جرب تاني بعد 24 ساعة.

2

جهز الفولدر

نزل Cursor وPython، اعمل فولدر اسمه job-agent، حط فيه الـ CV (مثلا cv.pdf)، وافتحه في Cursor.

3

خلي Cursor يبني الـ Agent

افتح شات الـ Agent في Cursor والصق ده:

Prompt البناء
Build a job agent in this folder:
1. Create profile.md with: job titles, location or Remote, years of experience, portfolio link, min_score: 60. Ask me to fill it.
2. Create .env with CALLMEBOT_PHONE and CALLMEBOT_APIKEY, and add .env to .gitignore.
3. Create send_whatsapp.py: it reads .env and sends my text to
   https://api.callmebot.com/whatsapp.php?phone=PHONE&text=TEXT&apikey=KEY
   (URL-encode the text). Use only the Python standard library.
4. Create jobs.csv with columns: date, title, company, link, score, missing, status.
5. Create .cursor/rules/job-agent.mdc with the scoring rules I will paste next.
4

حط قواعد التقييم

الصق ده في .cursor/rules/job-agent.mdc. Cursor بيقراه في كل تشغيلة، فالتقييم بيفضل ثابت.

قواعد التقييم
You are a strict recruiter. Compare my CV with each job description.

Score my fit from 0 to 100:
- 50 points: required skills and tools I clearly have
- 25 points: years and type of experience
- 15 points: industry and results that match
- 10 points: location, language and other requirements

Only count what is written in my CV. Do not guess.

For each job write: score, matched skills, missing skills,
and one line I can add or make clearer in my CV for this job.

WhatsApp message format (in Arabic):
وظيفة جديدة: {title} - {company}
تقييمك: {score} من 100
ناقصك: {top missing skill}
اللينك: {link}
5

املا بياناتك وجرب

اكتب بياناتك في profile.md، ورقمك بكود الدولة (+20) والـ API key في .env. بعدين قول لـ Cursor: Run send_whatsapp.py with a test message واتأكد إن الرسالة وصلتك.

6

شغله كل يوم

افتح شات جديد في الـ Agent والصق:

Prompt التشغيل اليومي
Run the job agent:
- Read my CV and profile.md.
- Search the web for job posts from the last 3 days that match my titles and location.
- Skip any link already in jobs.csv.
- Score each job with the rules in .cursor/rules/job-agent.mdc.
- Add every job to jobs.csv.
- For each job with score >= min_score, run send_whatsapp.py with the message format in the rules.
- Do not log in to any website and do not apply. I apply myself.

وهتوصلك رسالة زي دي:

وظيفة جديدة: Media Buyer
تقييمك: 85 من 100
ناقصك: خبرة TikTok Ads
اللينك: linkedin.com/jobs/...7:02 AM ✓✓
